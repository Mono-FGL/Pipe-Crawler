The repository has been organized with clean, chronological naming:

Version Structure:
- Each major version represents a development iteration
- Names follow pattern: [major].[minor]_[description]

Organized Directories:
- 1.x: Base prototypes (Base, Pic, BT05, Joystick)
- 2.x: Intermediate features (Combined Code, BNO055, Rotary Odometry)  
- 3.x+: Advanced features (3d_Mapping, IMU Calibration, etc.)

Tools Moved Outside 4 Wheel Robot:
- Python2D/: 2D graphing code
- Python3D/: 3D visualization and mapping
- TroubleshootWire/: Wiring documentation
- RVizSetup/: ROS visualization config
