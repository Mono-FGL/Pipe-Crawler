# Pipe-Crawler

A robot development repository organized chronologically.

## Repository Structure

### Root Level Files
- `fix_Section_b_FIX.md` - Fixes and modifications for Section b
- `fix_add_to_section_b_for_usb_part.md` - USB-related fixes for Section b  
- `ORGANIZATION_SUMMARY.md` - Documentation of organization changes

### 4 Wheel Robot Directory
Contains all robot development iterations organized by version:

- **1.x Versions** (Base prototypes)
  - Base, Pic, BT05_Scrapped, With_Joystick
  - Temp_and_Humidity, SD_Card
  
- **2.x Versions** (Intermediate features)
  - Combined Code, Picture, BNO055_Quaternion_data
  - Rotary odometry tracking distance
  
- **3.x Versions** (Advanced features)  
  - 3d_Mapping, Updated Final Turning
  - IMU Calibration Saved Data, Test

- **4.x+ Versions** (Later developments)
  - Small robot turning

- **Other Tools**
  - combined_code_for_graphing
  - imu_get_x,y_degrees
  - magnitude_angle_imu

### Python2D Directory  
2D graphing code and utilities.

### Python3D Directory
3D graphing, visualization, and mapping code.

### TroubleshootWire Directory
Wiring troubleshooting guides and documentation.

### RVizSetup Directory
ROS Visualization setup configurations.

## Versioning Scheme
All versions in `4 Wheel Robot/` follow the pattern `[major].[minor]_[description]`, making it easy to track development progression chronologically.
